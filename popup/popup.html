🚀 HƯỚNG DẪN SỬ DỤNG (HDSD):
1️⃣ Cài đặt ban đầu: Chọn AI (Gemini, Groq, DeepSeek...) ➔ Dán API Key ➔ Bấm "⚡ Kiểm Tra Kết Nối" ➔ Bấm "💾 Lưu & Sẵn Sàng".
2️⃣ Vào trang làm bài: Mở trang thi (Wayground hoặc Azota) ➔ Khung HUD nổi sẽ tự xuất hiện góc phải.
3️⃣ Cách kích hoạt giải:
- Câu hỏi chữ: Bôi đen câu hỏi ➔ Bấm Alt + Q để giải siêu tốc.
- Câu hỏi dạng hình ảnh / đồ thị: Bấm Alt + V (hoặc nút "📸 Chụp ảnh" trên HUD) ➔ AI Vision tự đọc hình và đưa ra đáp án.
- Chỉ điểm câu hỏi: Bấm Alt + S rồi nhấp chuột vào câu hỏi cần giải.
4️⃣ Phím tắt một chạm: Esc hoặc Alt + H (Đóng/ẩn nhanh HUD ngay lập tức), Alt + Q (Mở/Giải chữ), Alt + V (Giải câu hỏi ảnh), Alt + S (Chỉ điểm câu hỏi).
